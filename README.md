# Registro de Incidencias

Aplicación desarrollada en Android Studio con Jetpack Compose para la asignatura Técnicas de Producción Industrial de Software I.

## Semana 6: Interfaz con Estado y Retroalimentación
- Implementación de estado reactivo mediante `remember` y `mutableStateOf`.
- Captura de datos en campos de entrada (`OutlinedTextField`) para título y descripción.
- Reacción dinámica de la interfaz al presionar el botón de registro con retroalimentación visual al usuario.
